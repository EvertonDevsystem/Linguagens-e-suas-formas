sealed / permits / record / var

Hierarquias fechadas e classes imutáveis de dados.

sealed interface Forma permits Circulo, Retangulo {}
record Circulo(double raio) implements Forma {}
record Retangulo(double l, double a) implements Forma {}

var c = new Circulo(5.0);
System.out.println(c.raio());

Switch Expression com Pattern Matching & when

Avaliação exaustiva por tipo e guarda condicional.

Object obj = "Java 27";
String resumo = switch (obj) {
    case Integer i when i > 0 -> "Positivo: " + i;
    case String s             -> "Texto (" + s.length() + ")";
    case null                 -> "Nulo";
    default                   -> "Outro";
};

3. Biblioteca Padrão: Streams, Optional e Virtual Threads

Collections, Stream API & Optional

Transformação declarativa de listas e proteção contra null.

import java.util.*;

var langs = List.of("Java", "Python", "C", "C++", "C#");
var filtradas = langs.stream()
    .filter(l -> l.length() >= 3)
    .map(String::toUpperCase)
    .toList();

Optional<String> primeira = filtradas.stream().findFirst();
System.out.println(primeira.orElse("Vazia"));
Virtual Threads & Try-With-Resources

Concorrência leve e fechamento automático de recursos.

import java.util.concurrent.Executors;

try (var exec = Executors.newVirtualThreadPerTaskExecutor()) {
    exec.submit(() -> System.out.println("Virtual Thread OK"));
}
