Clique em um nó para inspecionar:
  • document

      • <head>
      • <body>

Clique em qualquer nó verde acima para ver sua função no DOM.
Exemplo A: Criar, Inserir e Remover Elementos
// 1. Selecionar elementos
const app = document.querySelector("#app");
const botoes = document.querySelectorAll(".btn");

// 2. Criar e inserir novo elemento
const aviso = document.createElement("div");
aviso.className = "alert alert-success";
aviso.textContent = "Elemento inserido via DOM!";
app.appendChild(aviso);

// 3. Ouvir eventos
aviso.addEventListener("click", () => aviso.remove());
Exemplo B: Manipular Classes CSS e Atributos (classList / dataset)

Alternando temas ou estados visuais sem recarregar a página.

const card = document.querySelector("#cartaoProduto");
const btnTema = document.querySelector("#btnTema");

btnTema.addEventListener("click", () => {
  card.classList.toggle("bg-dark");
  card.classList.toggle("text-white");
  console.log("ID do produto:", card.dataset.produtoId);
});
Exemplo C: Formulário Dinâmico e Lista de Tarefas

Capturando submit e renderizando itens na tela.

const form = document.querySelector("#formTarefa");
const lista = document.querySelector("#listaTarefas");

form.addEventListener("submit", (e) => {
  e.preventDefault();
  const texto = form.tarefa.value.trim();
  if (!texto) return;
  lista.insertAdjacentHTML("beforeend", `<li>${texto}</li>`);
  form.reset();
});

2. API REST & Anatomia do JSON

Fluxo Cliente ↔ Servidor
1. Front-end (fetch) 2. HTTP Request (POST + Headers + JSON) 3. Back-end (Java / C# / Python) 4. HTTP Response (201 Created + JSON)
Exemplo A: Enviando Dados (POST com JSON.stringify)
async function salvarUsuario(usuario) {
  const resp = await fetch("https://api.exemplo.com/usuarios", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(usuario)
  });
  if (!resp.ok) throw new Error(`HTTP ${resp.status}`);
  return await resp.json();
}

Exemplo B: Buscando CEP (GET na ViaCEP API)

Consumo real de API pública brasileira preenchendo o DOM.

async function buscarCep(cep) {
  const res = await fetch(`https://viacep.com.br/ws/${cep}/json/`);
  const dados = await res.json();
  if (dados.erro) {
    alert("CEP não encontrado!");
    return;
  }
  document.querySelector("#cidade").textContent = `${dados.localidade}/${dados.uf}`;
}
Exemplo C: Conversão JSON.parse e localStorage

Salvando e recuperando objetos JSON no navegador do usuário.

const config = { tema: "escuro", idioma: "pt-BR", atalhos: true };

// Objeto JS -> String JSON salva localmente
localStorage.setItem("preferencias", JSON.stringify(config));

// String JSON -> Objeto JS novamente
const salvo = JSON.parse(localStorage.getItem("preferencias"));
console.log(salvo.tema); // "escuro"
