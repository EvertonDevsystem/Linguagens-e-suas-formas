        "cliente": cliente,
        "qtd": len(itens),

    }

2. Pattern Matching, Dataclasses e Asyncio

match / case (Structural Pattern Matching)

Desestruturação estrutural de dicionários e sequências.

def processar_evento(evento: dict) -> str:
    match evento:
        case {"tipo": "clique", "x": x, "y": y}:
            return f"Clique em ({x}, {y})"
        case {"tipo": "tecla", "codigo": 27}:
            return "ESC pressionado"
        case _:
            return "Evento desconhecido"
@dataclass, Geradores & asyncio

Modelos imutáveis, avaliação preguiçosa e corrotinas concorrentes.

from dataclasses import dataclass
import asyncio

@dataclass(frozen=True)
class Usuario:
    nome: str
    admin: bool = False

async def buscar(id_user: int) -> Usuario:
    await asyncio.sleep(0.1)
    return Usuario(f"User-{id_user}", admin=(id_user == 1))

3. Biblioteca Padrão: Comprehensions, Pathlib e JSON

List & Dict Comprehensions

Filtragem e transformação expressiva de coleções.

langs = ["Java", "Python", "C", "C++", "C#"]
tamanhos = {lang: len(lang) for lang in langs if len(lang) >= 3}
# {'Java': 4, 'Python': 6, 'C++': 3}
Arquivos com pathlib e json

Leitura e gravação multiplataforma orientada a objetos.

from pathlib import Path
import json

arq = Path("config.json")
arq.write_text(json.dumps({"tema": "dark", "ativo": True}, indent=2), encoding="utf-8")
dados = json.loads(arq.read_text(encoding="utf-8"))
