Ponteiros e Alocação Dinâmica (malloc / free)

Reserva dinâmica de blocos contíguos na Heap e liberação segura.

#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int *vetor = calloc(5, sizeof(int));
    if (vetor != nullptr) {
        for (int i = 0; i < 5; i++) vetor[i] = (i + 1) * 10;
        printf("Item 2: %d\n", vetor[2]);
        free(vetor);
        vetor = nullptr;
    }
    return 0;
}
struct, union e Ponteiros de Função

Composição de registros e callbacks em baixo nível.

typedef struct {
    int id;
    double x, y;
} Ponto;

typedef int (*Operacao)(int, int);
int somar(int a, int b) { return a + b; }

Ponto p = { .id = 1, .x = 3.5, .y = 7.2 };
Operacao op = somar;
int res = op(10, 20); // 30

2. Strings Seguras, Arquivos (FILE*) e Bitwise

Manipulação Segura de Strings (snprintf)

Evitando estouro de buffer com limites explícitos de tamanho.

#include <stdio.h>
#include <string.h>

char destino[32];
snprintf(destino, sizeof(destino), "Linguagem: %s (%d)", "C", 23);
printf("%s | Tamanho: %zu\n", destino, strlen(destino));
Arquivos (fopen / fprintf / fclose) e Flags Bitwise

Gravação persistente em disco e máscaras de bits de hardware.

#include <stdio.h>
#include <stdint.h>

constexpr uint8_t FLAG_LER = 1 << 0;
constexpr uint8_t FLAG_ESC = 1 << 1;
uint8_t perm = FLAG_LER | FLAG_ESC;

FILE *f = fopen("log.txt", "w");
if (f) { fprintf(f, "Permissoes: %u\n", perm); fclose(f); }
