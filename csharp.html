record / struct / init / with

Tipos imutáveis com mutação não-destrutiva via expressão with.

public record Produto(string Nome, decimal Preco);

var p1 = new Produto("Teclado Mecânico", 350.00m);
var p2 = p1 with { Preco = 299.90m };
Operadores Nulos (?., ??, ??=) e Ranges

Acesso seguro a nulos e fatiamento moderno de arrays/spans.

string? apelido = null;
int tamanho = apelido?.Length ?? 0;
apelido ??= "Convidado";

int[] nums = [10, 20, 30, 40, 50];
int[] fatia = nums[1..4]; // [20, 30, 40]
int ultimo = nums[^1];    // 50

2. Pattern Matching, LINQ e Programação Assíncrona

Switch Expression & LINQ

Padrões relacionais e consultas funcionais encadeadas.

string Avaliar(double n) => n switch {
    >= 9.0 => "Excelente",
    >= 7.0 and < 9.0 => "Aprovado",
    _ => "Recuperação"
};

int[] vals = [1, 2, 3, 4, 5, 6];
var pares = vals.Where(x => x % 2 == 0).Select(x => x * 10).ToList();
async / await / Task<T>

Requisições HTTP assíncronas com HttpClient.

public async Task<string> ObterJsonAsync(HttpClient http, string url)
{
    using var resp = await http.GetAsync(url);
    resp.EnsureSuccessStatusCode();
    return await resp.Content.ReadAsStringAsync();
}

3. Biblioteca Padrão: JSON, Minimal APIs e Span<T>

Serialização Nativa com System.Text.Json

Conversão rápida de objetos C# para JSON sem dependências externas.

using System.Text.Json;

var curso = new { Nome = "Desenvolvimento Web", CargaHoraria = 120 };
string json = JsonSerializer.Serialize(curso);
Console.WriteLine(json); // {"Nome":"Desenvolvimento Web","CargaHoraria":120}

Criação de endpoints REST enxutos em poucas linhas.

var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

app.MapGet("/api/status", () => Results.Ok(new { online = true, versao = "C# 15" }));
app.Run();
