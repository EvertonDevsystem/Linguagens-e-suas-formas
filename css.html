1. Seletores, Flexbox e Grid

Variáveis CSS, :has() e CSS Grid Fluido

Tokens reutilizáveis e grade responsiva automática.

:root {
  --cor-primaria: #0f3d4d;
  --cor-acento: #14b8a6;
}

.grade-cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
  gap: 1.25rem;
}

.card:has(img) {
  border: 2px solid var(--cor-acento);
}
Flexbox, position: sticky e @keyframes

Barra fixa alinhada e animação suave por GPU.

.navbar {
  position: sticky;
  top: 0;
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 1rem;
}

@keyframes flutuar {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-6px); }
}

2. Glassmorphism, Tipografia Fluida e Container Queries

Efeito Vidro (backdrop-filter) & Tipografia clamp()

Cartões translúcidos e títulos que escalam sem quebras bruscas.

.painel-vidro {
  background: rgba(15, 61, 77, 0.75);
  backdrop-filter: blur(12px);
  border: 1px solid rgba(255, 255, 255, 0.2);
  border-radius: 16px;
}

.titulo-fluido {
  font-size: clamp(1.75rem, 3vw + 1rem, 3.25rem);
}
Container Queries (@container)

Componentes que se adaptam ao tamanho do contêiner pai, não só da tela.

.wrapper-card {
  container-type: inline-size;
}

@container (min-width: 420px) {
  .card-interno {
    display: flex;
    align-items: center;
    gap: 1rem;
  }
}
